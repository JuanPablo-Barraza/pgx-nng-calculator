# results

Aquí se encuentra un ejemplo del reporte que se puede generar al emplear la calculadora.


## Cómo abrir el reporte

GitHub muestra `nng_calculator.html` como código. Para verlo como
página web:

1. Abrir el archivo en GitHub y pulsar el botón de descarga.
2. Abrir el archivo descargado con un navegador.
